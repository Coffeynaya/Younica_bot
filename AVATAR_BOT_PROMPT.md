7. HEYGEN API ИНТЕГРАЦИЯ
═══════════════════════════════════════

Платформа: HeyGen (https://heygen.com)
Документация API: https://developers.heygen.com

Необходимые API-операции:
- Создание аватара из видео (custom avatar training)
- Генерация образов (avatar looks): POST /v1/photo_avatar/generate_looks
- Добавление образов: POST /v1/photo_avatar/add_looks
- Генерация видео: POST /v2/video/generate
- Проверка статуса: GET /v1/video_status.get
- Список аватаров: GET /v2/avatars
- Список голосов: GET /v2/voices

Лимиты:
- Avatar looks: до 500 на аватар
- Стили: Realistic, Pixar, Cinematic, Vintage, Noir, Cyberpunk
- Позы: half_body, close_up, full_body
- Ориентация: square, horizontal, vertical

11. ИНСТРУКЦИЯ ДЛЯ КЛИЕНТА
═══════════════════════════════════════

После создания аватара клиент получает:

1. ДОСТУП К TELEGRAM-БОТУ
   - Ссылка на бота: t.me/[bot_username]
   - Команда /start → бот показывает образы клиента

2. КАК СОЗДАТЬ ВИДЕО:
   - Нажать "🎬 Создать видео"
   - Выбрать образ (Деловой / Casual / Креативный)
   - Выбрать формат (горизонтальный / вертикальный / квадратный)
   - Отправить текст скрипта (до 5000 символов)
   - Дождаться генерации (обычно 2-5 минут)
   - Скачать готовое видео

3. СОВЕТЫ ПО НАПИСАНИЮ СКРИПТОВ:
   - Пишите как говорите, не как пишете
   - Делайте паузы через точки и запятые
   - Оптимальная длина: 200-500 слов (1-3 минуты видео)
   - Избегайте сложных аббревиатур
   - Укажите ударения в нетривиальных словах через заглавные буквы

4. ЛИМИТЫ:
   - Пакет "Старт": 10 мин видео/мес
   - Пакет "Бизнес": 30 мин видео/мес
   - Пакет "Премиум": безлимит
   - Баланс: команда /balance

5. ЗАКАЗАТЬ НОВЫЙ ОБРАЗ:
   - Команда /new_look или кнопка "➕ Новый образ"
   - Описать желаемый стиль
   - Менеджер подтвердит и создаст (1-2 рабочих дня)

12. АРХИТЕКТУРА СИСТЕМЫ

├── Бот-консультант (Telegraf) — привлечение клиентов
├── Бот-помощник (Telegraf) — генерация видео для клиентов

- HeyGen API → создание аватаров, генерация видео

- ProxyAPI/OpenAI → AI-ответы консультанта
- (опционально) S3 → хранение готовых видео
- (опционально) ЮKassa/Stripe → оплата пакетов

## ПОШАГОВЫЙ ПРОЦЕСС ЗАПУСКА

1. **Клиент предоставляет данные** (по чеклисту выше)
2. **Мы создаём ботов** (по промпту выше)
3. **Клиент приходит на съёмку** → записываем видео
4. **Загружаем видео в HeyGen** → обучаем аватар (2-4 часа)
5. **Создаём образы** через API → привязываем к клиенту в базе
6. **Отправляем клиенту доступ** к боту-помощнику
7. **Клиент генерирует видео** самостоятельно через бота
