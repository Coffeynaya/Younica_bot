3. БАЗОВЫЕ ПЛАТФОРМЫ И РЕЖИМЫ РАБОТЫ
═══════════════════════════════════════

Обязательные платформы:

1. Tilda
   - Для быстрых лендингов, сайтов услуг, промо-страниц, спецпроектов
   - Работа через доступ владельца/сотрудника, настройки сайта, формы, CRM, Zero Block
   - Важно: API Tilda в первую очередь используется для экспорта/синхронизации контента; для части редакторских изменений понадобится работа через интерфейс аккаунта или браузерную автоматизацию
   - Для API нужен Business Plan + Public Key / Secret Key

2. WordPress
   - Для корпоративных сайтов, блогов, SEO-структур, каталогов, проектов с гибкой кастомизацией
   - Работа через админку, плагины, тему, page builder, REST API, SFTP/SSH (если нужно)
   - Желательно наличие staging-среды перед правками на проде

3. 1C-Битрикс
   - Для корпоративных сайтов, каталогов, интеграций с бизнес-системами, более тяжёлых проектов
   - Работа через админку, файловый доступ, хостинг/сервер, dev/staging-копию, иногда через Git/SSH
   - Для серьёзных изменений желательно тестовое окружение и резервная копия

Дополнительно бот должен уметь работать с:
- уже действующим сайтом клиента
- тестовой копией сайта
- Figma-макетами
- Git-репозиторием
- сервером, хостингом, FTP/SFTP/SSH
- доменом и DNS
- аналитикой и CRM

   - Tilda

6. Сформировать план работ по этапам

Бот всегда должен:
- сначала делать диагностику, потом менять
- предупреждать о рисках для продакшена
- перед значимыми изменениями рекомендовать бэкап
- при необходимости сначала работать на копии/staging

- сохранять структуру проекта понятной для клиента

5. ЧТО БОТ ДОЛЖЕН УМЕТЬ ДЕЛАТЬ
═══════════════════════════════════════

Функции бота/агента:

1. Предпроектный бриф:
   - задать клиенту правильные вопросы
   - собрать цели, аудиторию, структуру, пожелания, ограничения
   - помочь выбрать платформу

2. Работа с новым сайтом:
   - предложить структуру страниц
   - предложить тексты по блокам
   - подобрать стиль
   - собрать лендинг/сайт на выбранной платформе
   - подключить формы, домен, базовую аналитику

3. Работа с действующим сайтом:
   - проанализировать текущий сайт
   - выявить слабые места в структуре, дизайне, текстах, скорости, доверии и конверсии
   - предложить улучшения
   - внедрить изменения по согласованному ТЗ

4. Работа со стилем:
   - снять и описать текущий стиль сайта клиента
   - снять и описать стиль референса
   - на их основе создать улучшенный стиль
   - при необходимости собрать новый стиль с нуля

5. Работа с брендбуком:
   - собрать мини-брендбук или полный брендбук
   - описать цвета, шрифты, сетку, кнопки, отступы, иконки, стиль фото, tone of voice
   - дать правила применения на сайте, в презентациях, соцсетях и рекламных материалах

6. Работа с интеграциями:
   - формы заявок
   - email-уведомления
   - Telegram-уведомления
   - CRM
   - аналитика
   - карты, чаты, пиксели, calltracking

7. БОТ/АГЕНТ-ИСПОЛНИТЕЛЬ

Исполнитель должен уметь:

1. Работать по ТЗ клиента:
   - получить задачу
   - уточнить недостающие данные
   - разбить на шаги
   - показать, что будет сделано
   - выполнить задачу в платформе или CMS

2. Работать с Tilda:
   - создавать страницы и дубли страниц
   - собирать блоки и Zero Block
   - обновлять тексты, карточки, CTA, формы
   - настраивать SEO-поля, редиректы, аналитику, домен
   - публиковать изменения после согласования

3. Работать с WordPress:
   - создавать и редактировать страницы, записи, шаблоны
   - обновлять тексты, медиа, формы, меню, виджеты
   - работать с Elementor/Gutenberg/другими builder-ами
   - настраивать SEO, аналитику, производительность
   - ставить/обновлять плагины только после проверки совместимости

4. Работать с 1C-Битрикс:
   - править контент и структуру разделов
   - обновлять шаблоны и блоки
   - настраивать формы, события, интеграции
   - работать через админку и/или файловый доступ
   - документировать технические изменения особенно подробно

5. Давать результат:
   - список выполненных работ
   - что изменено на сайте
   - что нужно проверить клиенту
   - рекомендации следующего шага

8. СТИЛЬ, РЕФЕРЕНСЫ И БРЕНДБУК
═══════════════════════════════════════

Бот должен уметь работать в трёх режимах:

1. Снять стиль с текущего сайта клиента:
   - палитра
   - типографика
   - композиция
   - характер визуала
   - стиль иконок
   - плотность интерфейса
   - тон текста

2. Снять стиль с понравившегося сайта-референса:
   - что именно нравится: строгость / премиальность / лёгкость / технологичность / женственность / минимализм / эмоциональность
   - какие элементы нравятся: первый экран / сетка / анимации / карточки / меню / формы / кейсы

3. Создать стиль с нуля:
   - на основе ниши
   - на основе ЦА
   - на основе позиционирования
   - на основе личных предпочтений заказчика

Правило:
- брать за основу принципы и настроение
- не копировать 1-в-1 чужие тексты, графику, иллюстрации и уникальные элементы бренда

Брендбук как доп. опция:

Мини-брендбук:
- логика бренда
- цветовая палитра
- шрифтовая пара
- кнопки и формы
- стилистика фото
- базовые правила для сайта

Полный брендбук:
- позиционирование
- архетип / характер бренда
- tone of voice
- цвета с кодами
- типографика
- UI-kit для сайта
- композиционные правила
- примеры блоков и страниц
- правила использования на сайте, в соцсетях, презентациях, рекламе

11. ПОДРОБНАЯ ИНСТРУКЦИЯ ДЛЯ КЛИЕНТА
═══════════════════════════════════════

Сценарий А: если сайта ещё нет

1. Определите задачу сайта:
   - получать заявки
   - продавать услугу
   - презентовать компанию
   - собирать каталог
   - запустить спецпроект

2. Выберите платформу:
   - Tilda — если нужен быстрый визуальный сайт, лендинг, сайт услуг
   - WordPress — если нужен гибкий сайт, блог, SEO, нестандартные страницы
   - 1C-Битрикс — если нужен более тяжёлый корпоративный проект, каталог, интеграции

3. Зарегистрируйте домен:
   - Рекомендуемые варианты для РФ: Reg.ru, RU-CENTER, Beget
   - Домен должен быть зарегистрирован на владельца бизнеса, а не на подрядчика
   - Сразу включите 2FA и сохраните доступы у владельца
   - Подготовьте данные администратора домена и технический контакт

4. Подготовьте материалы:
   - логотип
   - фото/видео
   - описание услуг
   - цены
   - контакты
   - кейсы
   - отзывы
   - юридические реквизиты

5. Передайте доступы:
   - к платформе / CMS
   - к домену
   - к аналитике
   - к CRM, если она уже есть

## МОИ РЕКОМЕНДАЦИИ ПО ПЛАТФОРМАМ ДЛЯ ЭТОГО ШАБЛОНА

### 1. Tilda
- Лучшая точка входа для быстрых коммерческих сайтов, лендингов и сайтов услуг
- Понятна большинству малого и среднего бизнеса в РФ
- Хорошо продаётся как услуга "сделаем быстро и красиво"

### 2. WordPress
- Нужен как гибкая и массовая платформа для проектов сложнее Tilda
- Подходит для SEO, блогов, нестандартной структуры, кастомных интеграций

### 3. 1C-Битрикс
- Нужен для корпоративного сегмента и проектов с тяжёлыми интеграциями в РФ
- Повышает доверие у B2B и у клиентов с более сложной инфраструктурой
