Что добавлено

Готовая точка входа для посетителей

Виджет на всех страницах

Скрипт можно подключить к любой странице сайта, а кнопка открытия остается доступной поверх контента.

API или Telegram

Если указан API endpoint, сообщения отправляются на сервер. Если нет, посетителю показывается кнопка перехода к Telegram-боту.

Без сборки

Интеграция работает как обычные HTML, CSS и JavaScript-файлы, поэтому сайт можно разместить на любом статическом хостинге.

Настройка

Укажите endpoint вашего бота

Внизу страницы подключен файл bot-widget.js. Для реального бота замените значения data-api-endpoint и data-bot-url на свои. 

<script
  src="./bot-widget.js"
  data-api-endpoint="https://example.com/api/bot"
  data-bot-url="https://t.me/younica_bot"
  defer></script>
